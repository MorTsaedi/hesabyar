# حساب‌یار (HesabYar)

نرم‌افزار حسابداری دسکتاپ، رایگان و متن‌باز فارسی.

[![مجوز MIT](https://img.shields.io/badge/License-MIT-blue.svg)](./LICENSE)

[English version](./README.md)

حساب‌یار یک سیستم حسابداری مدرن، کاملاً آفلاین و مخصوص کسب‌وکارهای ایرانی
است. برای شرکت‌های کوچک و متوسط، مغازه‌داران، فریلنسرها و دفاتر حسابداری
طراحی شده و برای همیشه رایگان و با مجوز MIT منتشر می‌شود.

---

## چرا حساب‌یار را ساختیم؟

- **رایگان برای همیشه.** نرم‌افزارهای حسابداری حرفه‌ای در ایران معمولاً
  پولی و بسته هستند. حساب‌یار یک سیستم حسابداری دوطرفه کامل را بدون هیچ
  هزینه‌ای و با مجوز متن‌باز MIT در اختیار همه قرار می‌دهد.
- **فارسی از پایه.** بیشتر ابزارهای حسابداری، ترجمه‌شده و دست‌وپا شکسته‌اند.
  حساب‌یار از روز اول حول زبان فارسی طراحی شده: چیدمان راست‌به‌چپ، تقویم
  جلالی (شمسی)، اعداد فارسی، قالب‌بندی ریال/تومان و مفاهیم حسابداری ایرانی
  (سند روزنامه، تراز آزمایشی، رسید دریافت/پرداخت، اظهارنامه و…).
- **آفلاین و خصوصی.** داده‌ها در یک پایگاه‌داده SQLite محلی روی دستگاه کاربر
  ذخیره می‌شوند؛ بدون نیاز به اینترنت، بدون ابر و بدون هیچ‌گونه جمع‌آوری
  اطلاعات، همراه با پشتیبان‌گیری خودکار.
- **مدرن و سبک.** با فناوری‌های روز (Tauri v2، React و Rust) ساخته شده است.
  نصب‌کننده آن فقط چند مگابایت است — در مقایسه با حدود ۱۵۰ مگابایت برنامه‌های
  Electron — چون Tauri از مرورگر داخلی خود سیستم‌عامل استفاده می‌کند.
- **باز و توسعه‌پذیر.** معماری ماژولار و آماده افزونه دارد؛ ماژول‌هایی مانند
  حقوق و دستمزد، دارایی ثابت، چک و مغایرت بانکی دقیقاً از دل همین معماری
  رشد کرده‌اند.

## امکانات

### حسابداری هسته
- پشتیبانی چندشرکتی با پایگاه‌داده جداگانه برای هر شرکت
- نمودار حساب سلسله‌مراتبی (سطوح نامحدود، انواع حساب و ارز)
- سند روزنامه دوطرفه با کنترل خودکار برابری بدهکار و بستانکار
- دفتر کل و دفتر معین
- تراز آزمایشی (چندستونی با فیلتر بازه تاریخ)
- اسناد افتتاحیه و اختتامیه و مدیریت سال مالی
- قالب‌های اسناد تکرارشونده

### گزارش‌های مالی
- تراز آزمایشی، دفتر کل، ترازنامه، صورت سود و زیان و جریان وجوه نقد
- گزارش‌های مقایسه‌ای دوره‌ای با ستون اختلاف و درصد
- گزارش‌ساز سفارشی
- ماژول بودجه: دوره‌های بودجه، بودجه هر حساب و مقایسه بودجه با عملکرد
- داشبورد با کارت‌های شاخص، نسبت‌های مالی و نمودارهای تعاملی
- خروجی PDF (jspdf + html2canvas) و Excel (SheetJS) با سرستون فارسی

### فروش، خرید و انبار
- اشخاص (مشتریان و تأمین‌کنندگان) با سقف اعتبار و شرایط پرداخت
- فاکتورهای فروش، خرید و پیش‌فاکتور با تخفیف و مالیات
- تخفیف پرداخت زودهنگام/دیرهنگام
- کاتالوگ کالا با سطح حداقل/حداکثر و نقطه سفارش
- گردش انبار (ورود/خروج/اصلاح)، ارزش‌گذاری میانگین موزون (WAC) و FIFO
- وضعیت موجودی، هشدار کسری کالا و گزارش ارزش موجودی
- لیست قیمت

### بانکداری
- حساب‌های بانکی متصل به حساب‌های دفتر کل
- رسید دریافت و رسید پرداخت
- ایجاد خودکار سند حسابداری برای هر رسید
- مدیریت چک و مغایرت بانکی

### چند ارزی
- مدیریت نرخ ارز و حساب‌های ارزی
- موتور تسعیر ارز خودکار همراه با سوابق

### مالیات و سامانه مودیان
- تنظیمات مالیات بر ارزش افزوده و نرخ مالیات هر کالا
- محاسبه خلاصه مالیات و اظهارنامه‌های مالیاتی (ایجاد/ثبت پرداخت/حذف)
- اتصال به سامانه مودیان و صدور صورتحساب الکترونیکی

### حقوق و دستمزد و دارایی ثابت
- کارکنان، قالب‌های حقوق و آیتم‌های حقوق
- دوره‌های حقوق و ریز پرداختی‌ها
- دفتر دارایی ثابت، خلاصه استهلاک و اجرای استهلاک

### سیستم
- پشتیبان‌گیری تأییدشده و بازیابی امن
- گزارش رویدادها و بازرسی تغییرات
- تنظیمات شرکت، تم روشن/تاریک و رابط کاربری راست‌به‌چپ

### کیفیت
- ۸ باینری تست دود (Smoke Test) برای بانکداری، پشتیبان‌گیری، جریان وجوه نقد،
  ارز، انبار، مودیان، مالیات و ماژول‌های جدید

## چرا Rust؟

بک‌اند حساب‌یار با زبان Rust نوشته شده و این انتخاب عمدی است:

- **ایمنی حافظه بدون زباله‌روب (Garbage Collector).** سیستم مالکیت و
  Borrow Checker خطاهای use-after-free، مسابقه داده (data race) و اشاره‌گر
  تهی را در زمان کامپایل می‌گیرد — برای نرم‌افزاری که با پول سر و کار دارد
  حیاتی است.
- **کارایی.** انتزاع‌های بدون هزینه و کد بومی، کوئری‌های SQLite، تجمیع
  گزارش‌ها و تسعیر ارز را حتی روی سیستم‌های ضعیف سریع می‌کنند.
- **باینری کوچک و سریع.** در کنار استفاده Tauri از مرورگر بومی، Rust حجم
  نصب‌کننده را حدود ۵ مگابایت و زمان اجرا را تقریباً آنی نگه می‌دارد؛ برخلاف
  Chromium همراه Electron.
- **صحت در زمان کامپایل.** سیستم نوع قوی Rust دسته‌ی بزرگی از خطاهای زمان
  اجرا را به خطای کامپایل تبدیل می‌کند؛ دقیقاً همان چیزی که در منطق حسابداری
  نیاز دارید.
- **همزمانی امن.** کارهای پایگاه‌داده، پشتیبان‌گیری و فراخوانی HTTP سامانه
  مودیان می‌توانند بدون خطر حالت مشترک، همزمان اجرا شوند.
- **اکوسیستم غنی و امتحان‌پس‌داده برای این حوزه:**
  - `rusqlite` (SQLite همراه) برای پایگاه‌داده محلی هر شرکت
  - `serde`/`serde_json` برای قرارداد تایپ‌شده JSON با فرانت‌اند React
  - `reqwest` + `rustls` برای ارتباط با سامانه مودیان
  - `rsa`، `aes-gcm`، `sha2`، `pbkdf2`، `hmac` و `base64` برای رمزنگاری و امضا
  - `chrono` برای تاریخ و `uuid` برای شناسه‌ها
- **یک زبان، سه پلتفرم.** همان هسته Rust روی ویندوز، macOS و لینوکس منتشر
  می‌شود.

## ساختار پروژه

```
hesabyar/
├── src/                     # فرانت‌اند React + TypeScript
│   ├── pages/               # یک پوشه برای هر صفحه
│   ├── components/          # چیدمان، رابط کاربری، ویزارد و اجزای مشترک
│   ├── stores/              # استورهای Zustand
│   ├── lib/                 # رابط Tauri، ابزارهای جلالی/قالب‌بندی/خروجی
│   └── types/               # واسط‌های مشترک TypeScript
├── src-tauri/               # بک‌اند Rust (Tauri v2)
│   ├── src/
│   │   ├── commands/        # دستورات Tauri برای هر ماژول
│   │   ├── db/              # لایه دسترسی به SQLite برای هر ماژول
│   │   ├── models/          # ساختارهای داده مشترک
│   │   ├── moadian/         # کلاینت سامانه مودیان
│   │   └── bin/             # باینری‌های تست دود
│   ├── capabilities/        # پیکربندی مجوزهای Tauri
│   └── tauri.conf.json      # پیکربندی برنامه و بسته‌بندی
├── database/migrations/     # مهاجرت‌های SQLite (001 تا 024)
├── index.html
├── package.json
└── vite.config.ts
```

## شروع کار

### پیش‌نیازها

- **Node.js** نسخه 20.19 یا بالاتر (نسخه 22 پیشنهادی)
- زنجیره‌ابزار **Rust** نسخه stable
- وابستگی‌های سیستمی Tauri v2 برای سیستم‌عامل شما
  ([راهنمای پیش‌نیازهای Tauri](https://v2.tauri.app/start/prerequisites/))

### توسعه

```bash
npm install

# اجرای برنامه دسکتاپ (Vite + بک‌اند Rust)
npm run tauri dev

# یا فقط فرانت‌اند در مرورگر (سرور Vite روی پورت 1420)
npm run dev
```

### بررسی‌ها

```bash
npm run lint                 # lint فرانت‌اند (oxlint)
npm run build                # بررسی TypeScript + ساخت فرانت‌اند
cd src-tauri && cargo check  # بررسی Rust
```

### تست‌های دود

```bash
cd src-tauri
cargo run --bin banking_smoke_test
cargo run --bin backup_smoke_test
cargo run --bin cashflow_smoke_test
cargo run --bin currency_smoke_test
cargo run --bin inventory_smoke_test
cargo run --bin moadian_smoke_test
cargo run --bin new_modules_smoke_test
cargo run --bin tax_smoke_test
```

## ساخت نصب‌کننده‌ها

بسته‌بند Tauri نصب‌کننده هر پلتفرم را تولید می‌کند:

```bash
npm run tauri build
```

| پلتفرم | خروجی‌ها |
|--------|-----------|
| ویندوز | `.msi` (WiX) و `.exe` (NSIS) |
| macOS   | `.app` و `.dmg` |
| لینوکس  | `.deb`، `.rpm` و `.appimage` |

خروجی‌ها در مسیر `src-tauri/target/release/bundle/` قرار می‌گیرند.

### CI/CD

GitHub Actions نصب‌کننده‌ها را به‌صورت خودکار می‌سازد:

- **`.github/workflows/ci.yml`** — روی هر push و pull request اجرا می‌شود:
  lint فرانت‌اند، ساخت TypeScript و `cargo check`.
- **`.github/workflows/build-installers.yml`** — نصب‌کننده‌های ویندوز و macOS
  را می‌سازد، آن‌ها را به‌عنوان خروجی (artifact) بارگذاری می‌کند و در تگ
  `v*` به یک نسخه (Release) گیت‌هاب متصل می‌کند.
